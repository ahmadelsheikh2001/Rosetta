# IBM RPA Studio 30.0.2 toolbox

Screenshots of every toolbox category, taken in the project's Studio on 2026-10-29
(`toolbox-01.png` … `toolbox-23.png`). Evidence of which commands exist (ADR-017); the script
syntax of each command comes from the IBM RPA 30.0.x reference
(`docs/formats/wal-30.0.2.md`).

Commands relevant to the current conversion, by toolbox category:

- **Base / Flow Control**: Case, Continue, Do-While, Else, Else If, End Case, End Do-While, End For Each,
  End If, End While, Execute Subroutines, For, For Each, Go to, Go to If, If, Insert Label,
  Interrupt Loop, Next, Otherwise, Repeat, Return from Subroutine, Run Subroutine, Run Subroutine If,
  Then, Until, When, While
- **Base / General**: Bind Process Variables, Delay, Evaluate, Execute Script, Get Parameter,
  Get Parameters, Get Vault Item, Handle Error, Log Message, Read CSV File, Recover From Error,
  Set Timeout, Stop Execution, Update Counter
- **Base / Text**: Change Text Case, Concatenate Texts, Count Occurrences in Text, Count Text Characters,
  Find Occurrences in Text, Format Text, Get Subtext, Join Text, Pad Text, Replace Text, Split Text,
  Trim Text Blanks (and others)
- **Base / Numeric**: Convert Number to Text, Convert Text to Number, Decrement Variable,
  Increment Variable, Truncate Number
- **Base / Date and Time**: Add Value to Date Time, Calculate Date Difference, Convert Date Time to Text,
  Convert Text to Date Time, Get Current Date and Time, Get Date From Date Time, Get Date Time Part
- **Base / Collection**: Add to Collection, Get List Item, Insert Item into List, Remove From List, …
- **Base / Dictionary**: Add to String Dictionary, Dictionary Contains Key, Get Dictionary Value,
  Remove from Dictionary, Update String Dictionary
- **Base / Files**: Copy File, Get File Information, Get Files, Move File, Read All Text, Write to File, …
- **Base / Environment**: Get Environment Variable, Set Environment Variable
- **Base / Tests**: Throw Exception (and test commands)
- **Base / Variables**: Assign Variable, Assign Variables, Assign Value to a Variable If
- **Windows / User Interface**: Show Message Box, Input Box, Take a Screenshot, …

Other categories present: Artificial Intelligence, Communication, Database, Natural Language,
Browser, Terminals, Windows (Controls, Office, PDF, SAP, OCR, …), Email, FTP, Queue, Workflow.
